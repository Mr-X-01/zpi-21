# Инструкция по работе с Git

## Клонирование репозитория
Для начала работы с репозиторием, его необходимо скопировать на локальный компьютер:
```bash
git clone <тут ссылка на gitHub репозиторий>  # Клонировать репозиторий
```

## Настройка пользователя
После клонирования, настройте имя пользователя и адрес электронной почты:
```bash
git config user.name "Дарья Меленцова"  # Назначить имя пользователя
git config user.email "ifireice@example.com"  # Привязать почту
```

## Работа с ветками
Создание и переключение между ветками:
```bash
git branch <название ветки>  # Создание новой локальной ветки
git checkout <название ветки>  # Переключение на выбранную ветку
```

## Регистрация изменений
Чтобы зарегистрировать изменения в репозитории, выполните следующие команды:
```bash
git add .  # Добавить все изменения в индекс
git commit -m "тут комментарий с выполненной задачей"  # Зафиксировать изменения с комментарием
git push  # Опубликовать изменения в удалённый репозиторий
git push --set-upstream origin <название ветки>  # Установить upstream для новой ветки
```

## Проверка состояния репозитория
Для проверки текущего состояния файлов в репозитории используйте:
```bash
git status  # Показать текущее состояние файлов (изменения, удаления, добавления)
```
```
